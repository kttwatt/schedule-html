# 📂 materials — เอกสารประกอบรายวิชา

โฟลเดอร์สำหรับเก็บเอกสารรายวิชา พยคร 627 (นโยบายสุขภาพกับภาวะผู้นำ)
หลักสูตรการพยาบาลเฉพาะทาง รุ่นที่ 55 กลุ่มที่ 1 (สาขาการพยาบาลปริศัลยกรรม)

> **หมายเหตุ:** เอกสารเป็นลิขสิทธิ์ของอาจารย์ผู้สอน/คณะ — ใช้เพื่อการศึกษาในชั้นเรียนเท่านั้น
> ไม่อนุญาตให้นำไปเผยแพร่ต่อ การเปิด repo เป็น public เพื่อให้สะดวกเปิดจากมือถือ คุณควรพิจารณาปิด repo เป็น private ถ้าต้องการความปลอดภัย

## โครงสร้างโฟลเดอร์

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `01-orientation-policy` | ปฐมนิเทศ, นโยบายสุขภาพ, เศรษฐศาสตร์/ระบบการเงินสุขภาพ (ผศ.พิเชต) |
| `02-leadership` | ภาวะผู้นำ, จริยธรรม/กฎหมาย, การสื่อสาร, กำลังคนสุขภาพ |
| `03-perioperative` | มโนมติการพยาบาลปริศัลยกรรม, การรับรองคุณภาพ (HA) |
| `04-health-assessment` | การประเมินภาวะสุขภาพ, การตรวจร่างกายระบบต่างๆ (PE) |
| `05-assignments` | ใบงาน/งานส่ง: rubric take-home, workshop, งานกลุ่ม |
| `06-seminars` | หัวข้อสัมมนา, รายชื่อกลุ่ม, เอกสาร Policy+Workforce |
| `07-reference-reading` | เอกสารอ่านประกอบเต็ม (FULLTEXT) |

## ไลบรารีลิงก์ (ตาม session ในตารางเรียน)

ลิงก์เอกสารใน `index.html` / `schedule.md` จะชี้ตามชื่อไฟล์ต้นทางที่ `~/notes/pykhr627/materials/`
เพื่อให้หน้าเว็บเปิดไฟล์ได้จริง ต้องมีไฟล์อยู่ในโฟลเดอร์นี้ตาม path ที่ HTML อ้างอิง
